### 🚀 What I'm working on

- **Legacy platform work at scale** — day job is a high-traffic EdTech product:
  maintaining a long-lived CakePHP codebase while incrementally migrating it to
  Laravel. Multi-app monolith (user, teacher, admin, API) on MySQL with a
  read-replica setup.
- **ERP & business systems** — Laravel + Inertia + React, with reporting,
  document generation (PDF/Excel) and role-based access.
- **Mobile apps** — React Native / Expo clients backed by REST APIs, built for
  offline-tolerant use in the field.
- **POS & desktop** — point-of-sale tooling with NativePHP.
- **API design** — Laravel and Node/Express services over MySQL, with JWT auth,
  rate limiting and background jobs.

---

### 💡 How I build

- Clean, documented design systems so UI stays consistent across a whole product.
- REST APIs first — one back end, many clients (web, mobile, desktop).
- Practical over clever: readable code, predictable structure, tested paths.
- Strangler-fig migrations: keep the legacy app stable and shippable while
  routing feature-by-feature onto the new stack. Backward compatibility first.
- Query-level performance as a habit — N+1 hunting, index and pagination review,
  and deliberate master vs. replica routing on read paths.
- Spec-driven delivery: written spec → plan → tasks → implementation → tests,
  with adversarial review before release.
